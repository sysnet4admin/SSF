## 총 교육 시간
**14시간** (4H + 4H + 2H + 2H + 2H)

- **바닐라 쿠버네티스**: Module 1에서 환경 설정
- **클라우드**: GKE (Google Kubernetes Engine) - 무료 크레딧 $300 제공 (90일)
- **AI 도구**: Claude Code - $22/월
- **로컬 환경**: MacBook에서 진행하나 수강생은 리눅스 터미널 환경을 구성하도록 가이드
